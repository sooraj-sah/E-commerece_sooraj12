## 📌 Project Overview

Traditional search systems rely purely on keyword matching. This project enhances user engagement using **Natural Language Processing (NLP)** and **Machine Learning Vector Search**:

1. **Content-Based Filtering:** Analyzes product metadata, titles, and descriptions.
2. **TF-IDF & Vector Space Modeling:** Converts text information into high-dimensional numerical vectors.
3. **Cosine Similarity Matching:** Calculates similarity scores between items in milliseconds.
4. **Instant Recommendations:** Recommends top complementary and alternative items when a user views any product.
